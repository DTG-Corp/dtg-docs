🎓 Cài đặt AloGolf — 5 phút chạy local

Sau bài này bạn sẽ có toàn bộ stack AloGolf chạy trên máy local — sẵn sàng phát triển và kiểm thử.

📋 Yêu cầu hệ thống​

Yêu cầuPhiên bản
Node.js22.x (khuyến nghị 22.13+)
pnpm9.x (dùng Corepack)
Docker & Docker Composev3+
Go (tùy chọn)1.24+ — nếu chạy realtime/analytics ngoài Docker

Bước 1: Clone repo​

git clone https://github.com/DTG-Corp/alogolf.git
cd alogolf

Bước 2: Cài dependencies​

# Bật Corepack nếu chưa có
corepack enable

# Cài đúng theo pnpm-lock.yaml
pnpm install --frozen-lockfile

⚠️ Luôn dùng --frozen-lockfile để đảm bảo cài đặt deterministic.

Bước 3: Cấu hình biến môi trường​

cp .env.example .env

Mở file .env và chỉnh các biến cần thiết:

  • DATABASE_URL — PostgreSQL connection string
  • Các biến Redis, MongoDB, MinIO (mặc định đã có sẵn cho Docker)

Bước 4: Chạy Docker stack​

# Dựng toàn bộ hạ tầng + services
docker compose up -d

Lần đầu sẽ mất vài phút để pull images và build. Sau khi hoàn tất, kiểm tra:

ServiceURL
Backend APIhttp://localhost:3005/api
Realtime healthhttp://localhost:8081/healthz
Analytics healthhttp://localhost:8082/healthz
MinIO Consolehttp://localhost:9001

Bước 5: Chạy database migration​

pnpm prisma:migrate

Lệnh này tạo và áp dụng migrations vào PostgreSQL. Nếu chạy lần đầu, nó sẽ tạo toàn bộ schema.

Bước 6: Chạy Webapp​

pnpm exec nx dev @alogolf/webapp -- -H 0.0.0.0 -p 3002

Mở trình duyệt vào http://localhost:3002 — bạn sẽ thấy màn hình đăng nhập AloGolf.

🎉 Hoàn tất!​

Bạn đã có môi trường phát triển AloGolf đầy đủ. Tiếp theo:

  • 🎓 Đăng nhập lần đầu — tạo tài khoản và vào hệ thống
  • 🏌️ Tổng quan AloGolf — hiểu kiến trúc hệ thống

Lệnh thường dùng​

Mục đíchLệnh
Chạy backendpnpm exec nx serve backend
Chạy webapppnpm exec nx dev @alogolf/webapp -- -p 3002
Build productionpnpm exec nx run-many -t build
Chạy testspnpm exec nx run-many -t test
Xem logs Dockerdocker compose logs -f backend
Dừng stackdocker compose down
