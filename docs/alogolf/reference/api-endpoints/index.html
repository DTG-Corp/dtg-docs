📚 API Endpoints — Danh sách REST API

Tài liệu tham khảo — không có hướng dẫn sử dụng, chỉ mô tả endpoint. API đầy đủ (Swagger/OpenAPI): truy cập http://localhost:3005/api/docs khi backend đang chạy.

Auth​

MethodEndpointMô tảAuth
POST/api/auth/registerĐăng ký tài khoản mới❌
POST/api/auth/loginĐăng nhập, trả về JWT❌
POST/api/auth/logoutĐăng xuất✅
POST/api/auth/refreshRefresh token✅
POST/api/auth/forgot-passwordGửi email đặt lại mật khẩu❌
POST/api/auth/reset-passwordĐặt lại mật khẩu❌

Users​

MethodEndpointMô tảAuth
GET/api/users/meThông tin người dùng hiện tại✅
PATCH/api/users/meCập nhật thông tin cá nhân✅
GET/api/usersDanh sách người dùng (admin)✅ Admin
GET/api/users/:idChi tiết người dùng✅ Admin
POST/api/usersTạo người dùng mới (admin)✅ Admin
PATCH/api/users/:idCập nhật người dùng✅ Admin
DELETE/api/users/:idXoá người dùng✅ Super Admin

Courses (Sân golf)​

MethodEndpointMô tảAuth
GET/api/coursesDanh sách sân golf❌
GET/api/courses/:idChi tiết sân golf (kèm hố, tee)❌
POST/api/coursesThêm sân golf mới✅ Admin
PATCH/api/courses/:idCập nhật sân golf✅ Admin
DELETE/api/courses/:idXoá sân golf✅ Super Admin
GET/api/courses/:id/holesDanh sách hố của sân❌
POST/api/courses/:id/holesThêm hố✅ Admin
PATCH/api/courses/:id/holes/:holeIdSửa hố✅ Admin
DELETE/api/courses/:id/holes/:holeIdXoá hố✅ Admin
GET/api/courses/:id/holes/:holeId/teesDanh sách tee❌
POST/api/courses/:id/holes/:holeId/teesThêm tee✅ Admin

Bookings​

MethodEndpointMô tảAuth
GET/api/bookingsDanh sách booking (lọc theo ngày/sân)✅
GET/api/bookings/:idChi tiết booking✅
POST/api/bookingsTạo booking mới✅
PATCH/api/bookings/:idCập nhật booking✅
DELETE/api/bookings/:idHủy booking✅
GET/api/bookings/available-slotsKhung giờ trống theo ngày & sân❌

Flights​

MethodEndpointMô tảAuth
GET/api/flightsDanh sách flight theo ngày✅
GET/api/flights/:idChi tiết flight (kèm golfer, caddie)✅
POST/api/flightsTạo flight mới✅ Admin
PATCH/api/flights/:idCập nhật flight✅ Admin
POST/api/flights/:id/assign-caddieXếp caddie cho flight✅ Admin
POST/api/flights/:id/assign-cartXếp xe golf✅ Admin
GET/api/flights/:id/scoresĐiểm số của flight✅
