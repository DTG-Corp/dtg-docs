📚 Environment Variables — Biến môi trường

Tài liệu tham khảo — danh sách biến môi trường, mô tả, và giá trị mẫu. File mẫu: .env.example tại thư mục gốc của repo.

Chung (Root)​

BiếnBắt buộcMô tảVí dụ
NODE_ENV✅Môi trườngdevelopment / production
LOG_LEVELCấp độ logdebug / info / warn / error
API_PREFIXPrefix API/api
CORS_ORIGINSOrigins được phép CORShttp://localhost:3002

Database​

BiếnBắt buộcMô tảGiá trị mặc định
DATABASE_URL✅PostgreSQL connection stringpostgresql://alogolf:alogolf@localhost:5432/alogolf
POSTGRES_DB✅Tên database (Docker)alogolf
POSTGRES_USER✅User (Docker)alogolf
POSTGRES_PASSWORD✅Password (Docker)alogolf
POSTGRES_PORTPort (Docker)5432

Redis​

BiếnBắt buộcMô tảGiá trị mặc định
REDIS_URL✅Redis connection stringredis://default:alogolf@localhost:6379
REDIS_PORTPort (Docker)6379
REDIS_PASSWORDPassword (Docker)alogolf

Auth (Cognito SSO)​

BiếnBắt buộcMô tả
COGNITO_USER_POOL_ID✅Cognito User Pool ID
COGNITO_CLIENT_ID✅Cognito App Client ID
COGNITO_REGION✅AWS Region (VD: ap-southeast-1)
JWT_SECRET✅Secret key cho JWT signing
JWT_EXPIRES_INThời hạn JWT (3600s = 1 giờ)

Storage (MinIO / S3)​

BiếnBắt buộcMô tảGiá trị mặc định
STORAGE_ENDPOINT✅Endpoint MinIO/S3http://localhost:9000
STORAGE_ACCESS_KEY✅Access keyalogolf
STORAGE_SECRET_KEY✅Secret keyalogolf123
STORAGE_BUCKET✅Bucket namealogolf-media
STORAGE_REGIONRegion (S3)ap-southeast-1
STORAGE_USE_SSLDùng HTTPS?false

Realtime Service (Go)​

BiếnBắt buộcMô tảGiá trị mặc định
PORT✅Cổng listen8081
REDIS_URL✅Redis cho realtimeredis://default:alogolf@localhost:6379
MQTT_BROKER_URLMQTT broker URLmqtt://localhost:1883
ANALYTICS_ENDPOINTIngest metrics về analyticshttp://analytics:8082/ingest

Analytics Service (Go)​

BiếnBắt buộcMô tảGiá trị mặc định
PORT✅Cổng listen8082
MONGO_URI✅MongoDB connectionmongodb://alogolf:alogolf@localhost:27017/analytics
MONGO_DB✅Database nameanalytics
MONGO_PORTPort (Docker)27017

Webapp (Next.js)​

BiếnBắt buộcMô tả
NEXT_PUBLIC_API_URL✅Backend API URL (client-side)
NEXT_PUBLIC_WS_URL✅WebSocket URL (client-side)
NEXT_PUBLIC_COGNITO_REGION✅Cognito region cho frontend
NEXT_PUBLIC_COGNITO_POOL_ID✅Cognito Pool ID cho frontend
NEXT_PUBLIC_COGNITO_CLIENT_ID✅Cognito Client ID cho frontend

MongoDB​

BiếnBắt buộcMô tảGiá trị mặc định
MONGO_URI✅MongoDB connectionmongodb://alogolf:alogolf@localhost:27017/analytics
MONGO_PORTPort (Docker)27017
MONGO_INITDB_ROOT_USERNAME✅Root user (Docker)alogolf
MONGO_INITDB_ROOT_PASSWORD✅Root password (Docker)alogolf

Notifications Service​

BiếnBắt buộcMô tả
PORT✅Cổng listen
DATABASE_URL✅PostgreSQL cho notifications
REDIS_URL✅Redis queue
SMTP_HOST✅SMTP server gửi email
SMTP_PORT✅SMTP port
SMTP_USER✅SMTP username
SMTP_PASS✅SMTP password
PUSH_ENABLEDBật push notification? true/false
FCM_SERVER_KEYFirebase Cloud Messaging key
